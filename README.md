# 邮轮客站停留分布与下一班次分流

业务资料均为合成记录。表头字段及跨表引用见 `fixtures/format.json`。

## 数据说明

所有时钟为船到港地时间。manifest 的 window 是预约值，notified_until 是此前已报旅客的最迟协助完成承诺。escort 对应需陪同的同行者，缺省表示服务可由场内人员独立完成。start 只是服务开始，pass 表示离开该队列。closed 禁止配置新服务，missing-gate 表示观察不全，二者不等价。从开始到 observation-cutoff 为已采集时段。walkways 是步行段，可走路径按轮椅标志区分，meet 是集合点。
capacity 中一名 helpers 同时最多给一个同行组服务。常规及协助服务的拟用工时可用相容的既往观测估计，缺乏足够资料时用有依据的范围或提示无法比较，不填写固定的等待数字。

CSV 使用 UTF-8、逗号分隔，无引号与内嵌换行。未提供的字段是空字符串，作为关系值的 `-` 表示不适用。多值字段用竖线分隔，数值和日期单位见业务约定。

## 资料检查

使用 Node.js 22.23.4，依赖仅为 Node.js 标准库。运行 `npm ci --ignore-scripts --offline` 准备工作区。

运行 `npm run check:materials` 检查合成交接资料的字段与记录引用。运行 `npm test` 检查交接资料的读取和校验。

## 分析工具

`npm run analyze -- <命令>` 或 `node tools/analyze.mjs <命令>`，公共选项：`--dir` 指定资料目录（默认 fixtures）、`--visit` 指定航次（默认最后一个）。所有输出为 JSON，时刻为 HH:MM；观察未闭合的上界显示为“未定/不可识别”，不编造数字。

- `summary`：航次概览、异常记录（重扫、换口、超采集时段、陪同者先行离开）、跨航次同组号提示。
- `paths`：每名旅客的观测序列与全部相容路径（按轮椅标志过滤、按步行分钟做时间可行性检验），多条相容路径并列。
- `waits`：按时段×服务类型分层的等待分布。区间删失用 Turnbull 估计，另给乐观/悲观界限；只有预约的人不进分层样本、单独计数；有快道证据（换口、停用期间通过、人工放行）的人从普通窗口对照中剔除。`--buckets 09:00,09:24,10:00` 可自定义分段。
- `compare`：航次对比，先讲群组构成、设备停用（closed 与 missing-gate 分列）、观察尾部完整性，再给可比范围。
- `plan`：分时放行方案评估。默认比较 S0、S0+S1、S0+S2 与错峰 5 分钟；`--arrange S0,S1 --release stagger:5 --service normal=3:11 --service assisted=8:20` 评估指定方案。服务时长缺省由相容既往观测估计（含排队、偏保守，附证据条数）；协助服务证据不足时只给资源与步行约束下的最佳情形，不填写固定等待数字。承诺逐一核对（守约/存疑/超出承诺/无法确认），不用普通队列平均值抵消协助超承诺。方案时段结束后沿用最后配置的容量。
- `outage`：区域停用影响。默认取该航次 closed 记录，也可 `--zone A --from 09:24 --to 09:50` 指定。给出受影响旅客的状态（在服务可完成/在队列须改道/仅预约）、以当前位置为起点的重走路径、须确认联络名单（已通知承诺、无陪同受助、需同行照料组合）、资料不足以承诺等待上限名单；停用期间完成者单列。
- `review`：旅客被告知的时段与事后估计的实际等待并列；资料目录存在 replies.csv（表头 `visit,person,response,new_window`）时并入真实回复与改约，供下一轮运营复核。
- `view --audience ops|airline`：现场视图按航次和小组给出各区域队列时间线与阻塞区间（推断进场已标注）；航司视图只给聚合指标，不出现个人标识。
- `report`：以上全部汇总。
- `serve --port 8080`：HTTP 视图服务，路由 `/ops/:visit`、`/airline/:visit`、`/report`。

### 估计约定

- 进场时刻：优先用该区域自己的 scan/start；否则按“无反证时径直步行进场”约定（大厅到达+步行分钟），逗留松弛度在 entry.slack 单列——若旅客在大厅逗留，真实队列等待更短。
- 离开时刻：有 pass 用 pass；无 pass 且区域有 missing-gate 时，离开不早于断报开始（期间可能有人未留记录地通过）；否则不早于 observation-cutoff。窗口未闭合的旅客等待只有下界。
- 同一同行组可分开领行李，组内不强求同队列；escort 组合与无陪同受助者在分流上有约束：无陪同受助者须占用协助人员，一名协助人员同时最多服务一个同行组。
